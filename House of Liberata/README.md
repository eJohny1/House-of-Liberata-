## 📌 Overview

**House of Liberata** is a fully responsive e-commerce website celebrating Cameroonian heritage through contemporary fashion. The platform showcases traditional boubous, Ankara wax prints, and culturally significant designs.

> *"Liberata means freedom. Freedom to be who you are, to wear where you come from."* — Emilienne, Founder

## ✨ Features

### 🛍️ E-Commerce Functionality
- Fully interactive shopping cart (add/remove, update quantities, real-time totals)
- Local storage persistence (cart saves between page reloads)
- Coupon system (LIBERATA10, SAVE20, FREESHIP, WELCOME15)
- 16+ products with images and pricing
- Product detail page with image gallery and size selection

### 📱 Responsive Design
- Desktop: Full layout with multi-column product grids
- Tablet: Collapsible navigation (max-width: 799px)
- Mobile: Single column layout with hamburger menu (max-width: 477px)

### 📄 Pages Included
- **Home** - Hero banner, featured products, new arrivals, promotions
- **Shop** - Full product catalog with pagination
- **Single Product** - Detailed product view with image gallery
- **Blog** - Cultural storytelling with 4 articles
- **About** - Brand story, artisans showcase, craft values
- **Contact** - Contact form, Google Maps, team profiles
- **Cart** - Shopping cart with coupon support

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Media Queries, Animations)
- JavaScript (ES6)
- FontAwesome 6
- Google Maps Embed API

## 🚀 Getting Started

1. Clone the repository
```bash
git clone https://github.com/yourusername/house-of-liberata.git
```

2. Navigate to project folder
```bash
cd house-of-liberata
```

3. Open the website
- Double-click `index.html` OR use Live Server in VS Code

No build process required!
